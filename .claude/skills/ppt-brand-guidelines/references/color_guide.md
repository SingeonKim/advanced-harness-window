# VRL 색상 가이드

## 주요 색상

### 라임 (주요 강조색)
- **HEX**: `#BDFF00`
- **RGB**: 189, 255, 0
- **HSL**: 75, 100%, 50%
- **사용처**: 핵심 강조, CTA, 브랜드 강조

### 다크 (기본 텍스트)
- **HEX**: `#0F172A`
- **RGB**: 15, 23, 42
- **HSL**: 222, 47%, 11%
- **사용처**: 헤드라인, 본문 텍스트, 어두운 배경

### 흰색
- **HEX**: `#FFFFFF`
- **RGB**: 255, 255, 255
- **사용처**: 배경, 어두운 표면의 텍스트

## 강조 색상

### 오렌지
- **HEX**: `#FF6B35`
- **RGB**: 255, 107, 53
- **사용처**: 보조 강조, 강조 포인트

### 라임 다크
- **HEX**: `#84CC16`
- **RGB**: 132, 204, 22
- **사용처**: 보조 강조, 성공 상태

### 슬레이트
- **HEX**: `#1E293B`
- **RGB**: 30, 41, 59
- **사용처**: 카드 배경, 섹션

| 이름 | Hex | 사용처 |

| 흰색 | `#FFFFFF` | 기본 배경 |

| Slate 300 | `#CBD5E1` | 테두리, 구분선 |

## 색상 조합

### 라이트 테마
- 배경: `#FFFFFF`
- 텍스트: `#0F172A`
- 강조: `#BDFF00`
- 약화: `#475569`

### 다크 테마
- 배경: `#0F172A`
- 텍스트: `#FFFFFF`
- 강조: `#BDFF00`
- 약화: `#CBD5E1`

## 대비 가이드라인

### 좋은 조합
- `#0F172A` 텍스트 on `#FFFFFF` 배경
- `#FFFFFF` 텍스트 on `#0F172A` 배경
- `#0F172A` 텍스트 on `#BDFF00` 배경
- `#BDFF00` 강조 on `#0F172A` 배경

### 피해야 할 조합
- `#BDFF00` 텍스트 on `#FFFFFF` (낮은 대비)
- `#84CC16` 텍스트 on `#FFFFFF` (낮은 대비)
- 밝은 배경에 밝은 텍스트

## 사용 규칙

1. **라임은 절제하여 사용**: 핵심 강조에만, 본문 텍스트에 절대 사용 금지
2. **텍스트에 다크 사용**: 밝은 배경의 읽기 가능한 텍스트에는 항상 `#0F172A` 사용
3. **강조에 오렌지 사용**: 라임의 보조로, 변화를 위해 사용
4. **일관된 배경 사용**: 주로 흰색 또는 slate-900 사용
