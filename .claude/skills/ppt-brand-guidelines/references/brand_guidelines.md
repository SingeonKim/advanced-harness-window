# VRL 브랜드 가이드라인

## 브랜드 아이덴티티

VRL은 현대적인 기술 기업입니다. 브랜드 미학:
- **미니멀**: 깔끔하고 군더더기 없는 디자인
- **현대적**: 현대적인 느낌, 기술 중심적
- **전문적**: 세련되고 신뢰감 있음
- **대담함**: 강조 색상의 자신감 있는 사용

## 시각적 언어

### 디자인 원칙

1. **단순성 우선**
   - 불필요한 요소 제거
   - 하나의 시각적 초점
   - 여유로운 여백

2. **높은 대비**
   - 밝은 배경에 어두운 텍스트
   - 중립적 배경에 강조 색상
   - 명확한 시각적 계층

3. **일관성**
   - 모든 자료에 동일한 색상
   - 균일한 여백과 정렬
   - 예측 가능한 레이아웃 패턴

## 타이포그래피

### 폰트 스택
```
기본: Inter, SF Pro, system-ui, sans-serif
코드: SF Mono, Fira Code, monospace
```

### 굵기 사용
- **Bold (700)**: 헤드라인, 강조
- **SemiBold (600)**: 소제목
- **Regular (400)**: 본문 텍스트
- **Light (300)**: 캡션, 보조 텍스트

### 크기 체계
| 요소 | 크기 | 굵기 |
|------|------|------|
| 타이틀 | 44-60px | Bold |
| 헤딩 | 32-40px | Bold |
| 소제목 | 24-28px | SemiBold |
| 본문 | 18-20px | Regular |
| 캡션 | 14-16px | Regular |

## 색상 적용

### 기본 사용
- **라임 (`#BDFF00`)**: 강조, CTA, 핵심 요소
- **다크 (`#0F172A`)**: 모든 텍스트, 어두운 배경
- **흰색**: 배경, 어두운 배경의 텍스트

### 강조 색상 사용
- **오렌지 (`#FF6B35`)**: 보조 강조
- **슬레이트 계열**: 보조 요소

### 규칙
- 라임은 강조에만 사용, 본문 텍스트에 절대 사용 금지
- 구성당 강조 색상 최대 2개
- 텍스트 대비 비율 4.5:1 이상 유지

## 레이아웃 가이드라인

### 여백
- 기본 단위: 8px
- 소: 8-16px
- 중: 24-32px
- 대: 48-64px

### 마진
- 슬라이드 가장자리: 최소 10%
- 요소 사이: 16-24px
- 섹션 구분: 48px+

### 정렬
- 본문 텍스트 왼쪽 정렬
- 타이틀 슬라이드 타이틀 중앙 정렬
- 섹션 내 일관된 정렬

## 프레젠테이션 특화

### 슬라이드 유형

**타이틀 슬라이드**
- 크고 중앙 정렬된 타이틀
- 왼쪽 상단 로고
- 선택적 부제목
- 어두운 또는 밝은 배경

**콘텐츠 슬라이드**
- 왼쪽 정렬 헤더
- 불릿 포인트 또는 핵심 정보
- 선택적 오른쪽 시각 자료
- 오른쪽 하단 로고

**섹션 구분자**
- 중앙 섹션 이름
- 단색 배경 (라임 또는 다크)
- 최소한의 요소

**데이터/차트 슬라이드**
- 명확한 차트 타이틀
- 단순화된 시각화
- 차트에 브랜드 색상 사용

### 애니메이션
- 애니메이션 최소화
- 페이드 전환 선호
- 화려한 효과 없음
- 0.3-0.5초 지속

## 보이스 & 톤

### 글쓰기 스타일
- 명확하고 직접적
- 기술적이지만 접근 가능한
- 자신감 있게, 거만하지 않게
- 전문적이지만 딱딱하지 않게

### 프레젠테이션 텍스트
- 짧은 문장
- 능동태
- 목록에 불릿 포인트
- 슬라이드당 하나의 아이디어

## 브랜드 금지 사항

- 로고에 그라디언트 사용 금지
- 3가지 이상의 색상 혼합 금지
- 복잡한 배경 사용 금지
- 슬라이드 과부하 금지
- 장식적 폰트 사용 금지
- 불필요한 그래픽 추가 금지
- 색상 팔레트 이탈 금지
